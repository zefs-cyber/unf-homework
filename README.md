# УНФ · Домашние задания

Домашние задания курса «Управленцы нового формата». Машрабов Диловар.

## Как опубликовать (первый раз)

1. На github.com нажмите **New repository**. Назовите его `unf-homework`, выберите **Public** и нажмите **Create repository**.
2. На странице нового репозитория нажмите **uploading an existing file**.
3. Откройте эту папку (`unf-homework`) в Finder, выделите всё содержимое (`index.html`, `homeworks.js`, `README.md` и папку `hw`) и перетащите в окно браузера. Папки надёжнее перетаскиваются в Chrome.
4. Внизу нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В «Build and deployment» выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, затем нажмите **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/unf-homework/`.

## Как добавить новое ДЗ

1. Создайте папку `hw/<дата>-<тема>/` (например, `hw/2026-10-07-sarcasm/`) и положите в неё страницу ДЗ под именем `index.html`.
2. В `homeworks.js` допишите объект в список `HOMEWORKS`: `id` (совпадает с именем папки), `module`, `date`, `type`, `title`, `subtitle`, `path`.
3. Если начался новый модуль, добавьте его в `MODULES`.
4. На github.com загрузите новую папку через **Add file → Upload files**, а `homeworks.js` поправьте прямо на сайте (значок карандаша). Сайт обновится через минуту.

Сайт сам открывает самое новое ДЗ. Каждое задание имеет свою ссылку: `…/unf-homework/#<id>`.

## Посмотреть локально

Откройте `Открыть сайт.command` в папке выше. Если открыть `index.html` двойным кликом, YouTube внутри страниц не проигрывается.
